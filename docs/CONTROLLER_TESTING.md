# 实体双手柄验收

## 当前状态

2026-10-07 用户确认「手柄操作测试已通过」。设备型号、连接方式及逐项测试记录未提供；下表保留详细验收项目，用于后续复测，不据此推断每个边界场景均已独立验证。输入设置、连移时序、映射冲突及死区转换另有自动化测试覆盖。

## 准备

1. 通过 USB 或 macOS 蓝牙设置连接两只支持扩展手柄布局的设备。
2. 执行 `swift script/controller_probe.swift` 检查系统识别结果。HID 与 GameController 枚举可能因设备协议不同而不同，以游戏中可用的扩展手柄为准。
3. 启动游戏，打开「设置 → 手柄诊断」，记录两只设备名称和玩家槽位。
4. 按下各个方向和按钮，检查当前输入、映射操作和摇杆轴值。设置窗口只显示诊断，不操作棋盘。
