# Neon Stack Roadmap

本路线图记录 Neon Stack 的改进方向，供开发和体验验收使用。条目按优先级推进，尚未承诺发布时间；未勾选的条目均为计划。

## 当前基础

- [x] RealityKit 棋盘、霓虹方块、落点投影及消行动效。
- [x] 单人挑战和本地同屏双人对战。
- [x] 七袋方块序列、SRS 旋转、暂存、五块预览及锁定延迟。
- [x] 同序列对战、垃圾行攻击、连击与攻击抵消。
- [x] 键盘和 GameController 输入、暂停及断连处理。
- [x] Liquid Glass 操作按钮及原生设置窗口。
- [x] 随等级切换的原创合成 BGM、不同消行数的音效、独立音频开关和音量保存。
- [x] 规则、音频播放和动效生命周期的自动化测试。

用户于 2026-10-07 确认手柄操作测试已通过；设备及逐项操作记录未提供，记录见 [手柄验收](CONTROLLER_TESTING.md)。当前应用使用本地临时签名，尚未公证。

| 已实现：输入设置 | 支持双玩家映射、连移延迟、移动间隔和死区；自动保存与恢复默认，已通过自动化测试，手柄操作测试由用户确认通过 |
| 已实现：经典菜单与手柄设置 | 主菜单 → 模式选择 → 321 开局；Menu / Esc 打开继续、结束、设置菜单；设置 LB / RB 切页、上下选择、左右调整、A 确认、B 返回；新增流程实机验收待用户确认 |
| 已完成：开局倒计时 | 开始与重新开局显示三秒倒计时；倒计时结束前不接受棋盘操作 |
| 已实现：攻击与垃圾行提示 | 清楚显示发送量、抵消量和待接收量；垃圾行进入前有提示，且不遮挡落点 |

## P1：持续游玩的目标

目标：让单人有可重复挑战的目标，让双人对战形成完整比赛。

| 计划 | 验收标准 |
| --- | --- |
| 已完成：本地最高分与历史成绩 | 按模式保存成绩；结果页提示新纪录；重启后保留；提供清理入口 |
| 40 行竞速 | 消除 40 行后结算用时，保存最佳成绩；暂停时间处理规则明确 |
| 限时挑战 | 在固定时间内比拼得分，明确倒计时和结束条件；成绩与其他模式分开记录 |
| 双人三局两胜 | 显示局分，每局结算后进入下一局；最终显示比赛胜者；可重新比赛或返回大厅 |
| 已完成：结果页统计 | 单人展示得分、有效用时、消行数、每分钟消行数及四行消除次数；双人补充双方抵消后发出攻击量和累计胜局比分；历史成绩同步保存 |
| 首次操作引导 | 根据键盘或手柄展示对应说明；可跳过和重新查看；不阻碍熟练玩家开局 |

建议下一轮优先实现 40 行竞速和双人三局两胜。

## 开发与验收原则

1. 规则和计分变化先明确行为，再以确定性测试验证；渲染和音效不得改变碰撞与胜负判定。
2. 交互变化需要在真实窗口中检查；手柄功能需要实体设备验收，不能以键盘测试替代。
3. 音频既验证播放状态，也检查真实听感；视觉反馈检查高强度场景和减少动效模式。
4. 每个条目完成实现与验收后再勾选；环境限制和未验证事项保留在文档中。

## 对战反馈与视觉优化

- 发送与抵消数来自真实锁定结算；待接收总量与下一批 8 行分段预告显示在棋盘旁，明确未消行锁定后进入及可先抵消。
- 危险边框稳定显示橙色或红色，不持续闪烁；依据锁定高度及下一批垃圾行预测。危险提示音提供独立开关和音量，按等级变化触发且每位玩家间隔至少 5 秒，暂停与静音期间不补播。
- 活动方块、哑光锁定块与空心白色投影区分；普通、四行、连击与全清形成颜色和强度层级，奖励文字放在棋盘上方并限制宽度。
- 单人信息面板改为升级目标与纪录进度；双人交互与危险提示前置，侧栏可滚动。
- 设置「声音与动效」提供减少动效并保存；尊重系统减少动态效果，开启时立即清理已有粒子，保留队列、奖励文本和稳定危险提示。

本轮验证：全套 65 项测试通过，最终奖励文字调整后追加 11 项表现与规则回归通过。真实窗口检查了空心投影、橙色／红色危险边框、双人反馈侧栏、新设置控件、放大后的棋盘上方奖励文字；通过真实键盘操作完成消行发送 1 行、对方待接收 1 行及锁定后实际进入 1 行的验证。抵消口径、四种动效层级、粒子上限、减少动效、提示音触发／限频／静音和设置保存由自动化测试覆盖。新增反馈的实体手柄体验及长期听感仍需用户确认。
