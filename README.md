# Neon Stack

基于 SwiftUI、RealityKit 和 GameController 的 macOS 俄罗斯方块，支持单人挑战和本地同屏双人对战。双人模式使用同一七袋方块序列，通过消行发送垃圾行。

后续计划与验收标准见 [Roadmap](docs/ROADMAP.md)。

## 启动

需要 macOS 15 或更高版本，以及支持 Swift 6 的 Xcode 工具链。当前在 Apple Silicon、Xcode 27 上完成构建与启动验证。

在项目目录执行：

```sh
./script/build_and_run.sh
```

脚本会停止已有 NeonTetris 进程、构建应用、生成 `dist/NeonTetris.app` 并启动。生成的应用使用本地临时签名，尚未公证。Codex 的 Run 按钮使用同一脚本。

```sh
swift test                          # 规则测试
./script/build_and_run.sh --verify   # 构建、启动并检查进程
./script/build_and_run.sh --debug    # LLDB
./script/build_and_run.sh --logs     # 进程日志
```

## 游戏模式

默认进入「单人挑战」。在顶部选择「单人挑战」或「双人对战」，再点击「开始游戏」。游戏进行中，先点击「返回大厅」结束当前游戏，再切换模式；已结束的游戏可直接切换。

- 单人挑战：一个居中的棋盘，不发送或接收垃圾行；消行计分，每消除 10 行升级加速。堆顶后显示最终得分和消行数，可重新开始。
- 双人对战：两个棋盘、独立计分、相同方块序列和垃圾行攻击，沿用下方对战规则。

单人模式支持第一只手柄，也支持下表中的两套键盘布局，两套键盘都操作同一棋盘。双人模式两套键盘分别操作对应玩家。单人模式忽略第二只手柄的输入，第二只手柄断开不会暂停单人游戏。

## 手柄操作

先在 macOS 中连接手柄，再启动游戏。应用自动发现支持 `extendedGamepad` 的设备，并将前两只手柄绑定到玩家一、玩家二；界面显示设备名称。手柄保持绑定，断开后比赛暂停，重新连接后手动继续。双人模式也可以使用一只手柄配合另一方的键盘。

| 操作 | 手柄 | 玩家一键盘 | 玩家二键盘 |
| --- | --- | --- | --- |
| 左右移动 | 方向键 / 左摇杆 | A / D | ← / → |
| 软降 | 向下 | S | ↓ |
| 顺时针旋转 | A | W | ↑ |
| 逆时针旋转 | B | Q | , |
| 暂存 | X / LB | E | . |
| 硬降 | Y / RB / 向上 | 空格 | Enter |
| 暂停 / 继续 | Menu | Esc | Esc |

手柄 Menu 可在初始界面开始比赛，在结果界面重新开局。窗口失去焦点时自动暂停。

按钮名称按 Xbox 布局描述，其他手柄按 GameController 的对应位置映射。实际设备支持取决于 macOS 是否识别为扩展手柄；当前没有连接实体手柄，双手柄绑定、长按连移、断连与重连仍需实机验收。

## 对战规则

- 棋盘为 10 × 20，支持落点投影、五块预览、暂存、SRS 旋转和 0.5 秒锁定延迟。
- 左右长按首次延迟 170 毫秒，随后每 45 毫秒移动一次；锁定延迟最多重置 15 次。
- 消除一、二、三、四行分别发送 0、1、2、4 行攻击；连续四行消除额外发送 1 行，连续消行提供最多 4 行连击攻击。
- 攻击优先抵消自己的待接收垃圾行，剩余部分发送给对手。
- 未消行的方块锁定后接收垃圾行，每次最多 8 行；每行有一个空位。
- 每消除 10 行提升下落速度。方块在棋盘顶部无法完整锁定，或垃圾行顶出已有方块时判负。
- 当前未实现 T-spin 特殊计分、操作音效、震动、联网对战和排行榜。

## 消行动效与 BGM

消行时显示横向光束、按原方块颜色飞散的碎片、扩散光环和消行提示。四行消除使用金色光环与「TETRIS!」提示。动画持续不到一秒，独立于棋盘消行和碰撞判定，短期粒子数量有上限，结束后自动清理。

底部「减少动效」关闭碎片、光环和浮动文字，保留短暂细光束；系统开启「减少动态效果」时也采用此模式。

BGM 使用程序合成的原创电子乐，包含旋律、和弦、低音、底鼓和节奏声部，无需下载音频资源。

- 每个等级根据等级编号生成不同旋律与和声，节奏从 100 BPM 逐渐加快，最高为 184 BPM。
- 升级时用一秒交叉淡入淡出切换曲目。单人按当前等级选曲，双人按双方最高等级选曲。
- 游戏暂停、手柄断连、窗口失去焦点和游戏结束时暂停音乐；返回大厅停止音乐，重新开始生成一级曲目。
- 底部显示当前等级与曲目名；点击「设置」或按 ⌘, 打开设置窗口，独立调整背景音乐和消行音效的开关与音量。
- 消除 1–4 行播放不同的原创合成音效，四行消除使用更丰富的上升音阶；设置中可试听。
- 打开设置会暂停游戏，关闭设置后点击「继续」恢复。

音乐在后台线程生成，避免阻塞输入和游戏规则。音频开关和音量自动保存，重启应用后保留；减少动效选项在关闭后恢复默认值。

## 工程结构

- `Sources/TetrisCore`：确定性规则、SRS、七袋序列、计分、游戏模式和垃圾行处理。
- `Sources/NeonTetris/Services`：比赛状态、双手柄绑定、键盘输入、帧循环和 BGM 播放。
- `Sources/NeonTetris/Views`：RealityKit 场景、消行粒子、SwiftUI HUD 和方块预览。
- `Tests/TetrisCoreTests`：随机序列一致性、硬降、暂存、消行、抵消、垃圾行、旋转、堆顶、单人隔离和双人攻击路由验证。

规则使用离散网格计算；RealityKit 负责场景渲染和动画，渲染帧率不参与碰撞判定。

`Tests/NeonTetrisTests` 验证真实音频播放器的等级切换、暂停恢复与静音，并验证 RealityKit 粒子的生命周期和减少动效模式。
