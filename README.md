# Neon Stack

基于 SwiftUI、RealityKit 和 GameController 的 macOS 俄罗斯方块，支持单人挑战和本地同屏双人对战。双人模式使用同一七袋方块序列，通过消行发送垃圾行。

后续计划与验收标准见 [Roadmap](docs/ROADMAP.md)。

## 启动

需要 macOS 15 或更高版本，以及支持 Swift 6 的 Xcode 工具链。当前在 Apple Silicon、Xcode 27 上完成构建与启动验证。

在项目目录执行：

```sh
./script/build_and_run.sh
```

脚本会停止已有 NeonTetris 进程、构建应用、生成 `dist/NeonTetris.app` 并启动。生成的应用使用本地临时签名，尚未公证。Codex 的 Run 按钮使用同一脚本。

制作 Apple Silicon 与 Intel 双架构的 Release DMG：

```sh
./script/package_universal_dmg.sh
```

产物为 `dist/NeonStack-universal.dmg`，可将磁盘映像中的 Neon Stack 拖入“应用程序”。脚本不会关闭正在运行的游戏。该安装包使用本地临时签名，尚未正式签名或公证；最低支持 macOS 15。

```sh
swift test                          # 规则测试
./script/build_and_run.sh --verify   # 构建、启动并检查进程
./script/build_and_run.sh --debug    # LLDB
./script/build_and_run.sh --logs     # 进程日志
```

## 游戏模式

默认进入「单人挑战」。在顶部选择「单人挑战」或「双人对战」，再点击「开始游戏」。游戏进行中，先点击「返回大厅」结束当前游戏，再切换模式；已结束的游戏可直接切换。

- 单人挑战：一个居中的棋盘，不发送或接收垃圾行；消行计分，每消除 10 行升级加速。堆顶后显示最终得分和消行数，可重新开始。
- 双人对战：两个棋盘、独立计分、相同方块序列和垃圾行攻击，沿用下方对战规则。

单人模式支持第一只手柄，也支持下表中的两套键盘布局，两套键盘都操作同一棋盘。双人模式两套键盘分别操作对应玩家。单人模式忽略第二只手柄的输入，第二只手柄断开不会暂停单人游戏。

## 手柄操作

先在 macOS 中连接手柄，再启动游戏。应用自动发现支持 `extendedGamepad` 的设备，并将前两只手柄绑定到玩家一、玩家二；界面显示设备名称。手柄保持绑定，断开后比赛暂停，重新连接后手动继续。双人模式也可以使用一只手柄配合另一方的键盘。

| 操作 | 手柄 | 玩家一键盘 | 玩家二键盘 |
| --- | --- | --- | --- |
| 左右移动 | 方向键 / 左摇杆 | A / D | ← / → |
| 软降 | 向下 | S | ↓ |
| 顺时针旋转 | X | W | ↑ |
| 逆时针旋转 | Y | Q | , |
| 暂存 | B / LB | E | . |
| 硬降 | A / RB / 向上 | 空格 | Enter |
| 暂停 / 继续 | Menu | Esc | Esc |

手柄 Menu 可在初始界面开始比赛，在结果界面重新开局。窗口失去焦点时自动暂停。

按钮名称按 Xbox 布局描述，其他手柄按 GameController 的对应位置映射。实际设备支持取决于 macOS 是否识别为扩展手柄；当前没有连接实体手柄，双手柄绑定、长按连移、断连与重连仍需实机验收。

## 输入设置与手柄诊断

点击「设置」或按 ⌘,，在「操作」分页调整输入：

- 连移首次延迟：50–500 ms，默认 170 ms。
- 连续移动间隔：16–150 ms，默认 45 ms；间隔越小越快，实际触发频率受游戏帧循环限制。软降直接使用此间隔。
- 摇杆死区：10%–90%，默认 50%；仅影响左摇杆，方向键保持数字输入并在对应轴优先。
- 分别选择玩家 1 / 2 的键盘和手柄映射；单人仍接受两套键盘布局，但仅接受第一只手柄。
- 键盘支持字母、数字、方向键、逗号、句号、空格、Enter 和 Esc，按物理位置绑定。两位玩家按键不能冲突，暂停键可以共用。
- 手柄方向和 A/B/X/Y、LB/RB、LT/RT、Menu 均可映射或取消绑定；每位玩家至少保留一个暂停按钮，可将多个按钮绑定到同一操作。
- 输入设置自动保存，可恢复默认。游戏内键盘提示随映射更新。

「手柄诊断」分页展示真实设备绑定、实时按键、摇杆轴值和映射操作；窗口中的手柄输入不会操作游戏。实体测试流程与当前结果见 [手柄验收记录](docs/CONTROLLER_TESTING.md)。

## 对战规则

- 棋盘为 10 × 20，支持落点投影、五块预览、暂存、SRS 旋转和 0.5 秒锁定延迟。
- 左右长按默认首次延迟 170 毫秒，随后每 45 毫秒移动一次；两项均可在设置中调整；锁定延迟最多重置 15 次。
- 消除一、二、三、四行分别发送 0、1、2、4 行攻击；B2B 困难消除额外发送 1 行，连续消行提供最多 4 行连击攻击。
- 攻击优先抵消自己的待接收垃圾行，剩余部分发送给对手。
- 未消行的方块锁定后接收垃圾行，每次最多 8 行；每行有一个空位。
- 每消除 10 行提升下落速度。方块在棋盘顶部无法完整锁定，或垃圾行顶出已有方块时判负。
- 当前未实现震动、联网对战和排行榜。

## 高阶操作奖励

以下为 Neon Stack 的项目规则。得分使用本次锁定前的等级倍率，软降和硬降分数另计。

- T-spin：T 方块最后一次成功操作为旋转，锁定时中心四角至少三角被占用。左右边界和底部视为占用，顶部外侧不算。朝向的两前角均占用为完整 T-spin，否则为 Mini；使用 SRS 第五个踢墙测试成功时升级为完整 T-spin。
- 成功平移、软降、重力下降或有距离的硬降会取消旋转资格；失败操作和零距离硬降保留资格。暂存及生成新方块清除资格。
- Back-to-back（B2B）：四行消除及消行 T-spin（包括 Mini）可相互串联。首次建立链，后续困难消除基础得分乘 1.5、攻击加 1 行；无消行保留链，普通一至三行消除中断链。无消行 T-spin 有分数，但不建立或触发 B2B 奖励。
- 连击：连续消行从第二次起，每次增加 `50 × 连击序号 × 等级` 分；攻击保留原有每两级连击加 1 行、最多加 4 行。无消行重置连击。
- 全清：消行后棋盘为空，额外增加下表分数及 10 行攻击。全清本身不改变 B2B 资格。
- 总攻击先抵消自己的待接收垃圾行，再将剩余攻击发送给对手；单人仅计分。HUD 和消行动效显示奖励名称，HUD 的攻击数为抵消前总量。

| 操作 | 基础分数（乘等级） | 基础攻击 |
| --- | --- | --- |
| 普通消除 1 / 2 / 3 / 4 行 | 100 / 300 / 500 / 800 | 0 / 1 / 2 / 4 行 |
| Mini：无消行 / 1 行 / 2 行 | 100 / 200 / 400 | 0 / 0 / 1 行 |
| 完整 T-spin：无消行 / 1 行 / 2 行 / 3 行 | 400 / 800 / 1200 / 1600 | 0 / 2 / 4 / 6 行 |
| 全清额外奖励：1 / 2 / 3 / 4 行 | 800 / 1200 / 1800 / 2000 | 额外 10 行 |
| B2B 四行全清额外奖励 | 3200（替代 2000） | 额外 10 行 |

全清额外分数和连击分数不参与 B2B 的 1.5 倍计算。例如一级首次四行全清得 2800 分、产生 14 行攻击；紧接一次 B2B 四行全清得 4450 分、产生 15 行攻击。

## 消行动效与 BGM

消行时显示横向光束、按原方块颜色飞散的碎片、扩散光环和消行提示。四行消除使用金色光环与「TETRIS!」提示。动画持续不到一秒，独立于棋盘消行和碰撞判定，短期粒子数量有上限，结束后自动清理。

底部「减少动效」关闭碎片、光环和浮动文字，保留短暂细光束；系统开启「减少动态效果」时也采用此模式。

BGM 使用程序合成的原创电子乐，包含旋律、和弦、低音、底鼓和节奏声部，无需下载音频资源。

- 每个等级根据等级编号生成不同旋律与和声，节奏从 100 BPM 逐渐加快，最高为 184 BPM。
- 升级时用一秒交叉淡入淡出切换曲目。单人按当前等级选曲，双人按双方最高等级选曲。
- 游戏暂停、手柄断连、窗口失去焦点和游戏结束时暂停音乐；返回大厅停止音乐，重新开始生成一级曲目。
- 底部显示当前等级与曲目名；点击「设置」或按 ⌘, 打开设置窗口，独立调整背景音乐、消行音效和操作音效的开关与音量。
- 消除 1–4 行播放不同的原创合成音效，四行消除使用更丰富的上升音阶；设置中可试听。
- 成功旋转播放短促音效；自然锁定与硬降分别播放不同反馈，硬降不叠加锁定音。旋转音效每位玩家独立限频，音频播放器使用有上限的常驻池复用；停止或重开时保留对象，避免结束回调访问提前释放的播放器。
- 消行音效实际播放时，BGM 快速降低至设定音量的 30%，保持约 350 ms 后平滑恢复；连续消行延长压低时间，暂停、静音和返回大厅清除压低状态，不改变保存的音乐音量。
- 打开设置会暂停游戏，关闭设置后点击「继续」恢复。

音乐在后台线程生成，避免阻塞输入和游戏规则。音频开关和音量自动保存，重启应用后保留；减少动效选项在关闭后恢复默认值。

## 工程结构

- `Sources/TetrisCore`：确定性规则、SRS、七袋序列、计分、游戏模式和垃圾行处理。
- `Sources/NeonTetris/Services`：比赛状态、双手柄绑定、键盘输入、帧循环和 BGM 播放。
- `Sources/NeonTetris/Views`：RealityKit 场景、消行粒子、SwiftUI HUD 和方块预览。
- `Tests/TetrisCoreTests`：随机序列一致性、硬降、暂存、消行、抵消、垃圾行、旋转、堆顶、单人隔离和双人攻击路由验证。

规则使用离散网格计算；RealityKit 负责场景渲染和动画，渲染帧率不参与碰撞判定。

`Tests/NeonTetrisTests` 验证真实音频播放器的等级切换、暂停恢复与静音，并验证 RealityKit 粒子的生命周期和减少动效模式。

### 成绩、倒计时与诊断

开始和重新开局有三秒倒计时，期间不接受棋盘操作，暂停会冻结倒计时。成绩按单人、双人分别保存，双人最高分取双方较高值；已结束的对局保存双方得分、消行数、用时和胜者，每个模式保留最近 100 局。结果页提示新纪录，设置中的「成绩」可查看或清理历史与最高分。中途退出对局不记录成绩。

设置中的「日志」可打开 `~/Library/Logs/NeonStack`。最多保留三份约 500 KB 的 JSONL 日志，记录关键操作前后状态、音效播放和异常；意外退出后重新启动，可将这些日志与 macOS 崩溃报告一起用于分析。日志留在本机，不自动上传。

### 游戏菜单与手柄设置

进入应用显示主菜单：开始游戏、设置。选择开始游戏后进入单人 / 双人模式选择，确认后显示 3、2、1 倒计时。游戏中 Menu / Esc 打开暂停菜单，提供继续游戏、结束游戏、设置；结束游戏返回主菜单，中途结束不保存成绩。结果页可再次开始或返回主菜单。

方向键 / 左摇杆选择，A 确认；模式页及设置页 B 返回。大厅与暂停菜单响应任一手柄，单人棋盘只响应第一只手柄。菜单按键固定，棋盘映射保持可配置；跨菜单和游戏切换时需松开已按住的按钮，避免确认键误触硬降。

设置在游戏内显示：LB / RB 切换声音、操作、成绩、手柄诊断、日志页；上下选择项目，左右调整，A 切换或执行，B 返回。支持音频开关与音量、双玩家手柄和键盘映射、连移延迟、移动间隔及摇杆死区。设置自动保存，改键跳过冲突键；清理成绩需要再次按 A 确认，返回或换项目取消确认。游戏中进入设置保持暂停，返回后须选择继续游戏。macOS 设置窗口也使用同一套手柄设置界面。

设置当前页签使用青色描边与文字高亮，项目焦点使用黄色描边。有手柄连接时显示手柄提示；没有手柄时显示键盘提示：菜单 ↑ / ↓ 选择、Enter 确认，模式页 Esc 返回；设置 PgUp / PgDn 切页、上下选择、左右调整、Enter 确认、Esc 返回。棋盘旁的操作说明按对应玩家是否连接手柄切换。

设置控件按类型展示：音频开关使用 Switch、音量使用 Slider、玩家和模式及手柄映射使用下拉选择、连移和死区使用数值 Stepper、键盘映射使用按键捕获绑定按钮；键盘 PgUp / PgDn 切页，手柄 LB / RB 不变。绑定冲突会提示，Esc 取消绑定。

### 结果统计

结果页和历史成绩展示得分、有效用时、消行数、每分钟消行数及四行消除次数。用时排除倒计时和暂停；每分钟消行数为消行数 × 60 / 有效秒数，零秒对局显示 0。双人补充双方发出的攻击行数（抵消后实际发送量）及累计胜局比分。结果页重开保留局分，结束游戏返回主菜单或切换模式后重置，平局不增加胜局；三局两胜仍是计划功能。旧历史缺少的新统计显示「—」。

### 背景图片

在「设置 → 背景」选择应用界面，再切换背景图片。内置 10 张原创背景：极光静湖、紫夜星云、霓虹雨城、晶体光场、月映山湖、星环沙海、深海微光、落日脉冲、萤火竹林和流光丝绸。可点击缩略图或下拉选择，手柄及键盘在「背景图片」项使用左右方向切换；开始界面和游戏界面独立保存。

「选择本机图片」打开系统文件选择器。图片导入时在后台缩小至最长边不超过 2560 像素，转换为 JPEG 并保存到 `~/Library/Application Support/NeonStack/Backgrounds`；开始界面与游戏界面各保留一张本机图片副本，原图移动后仍可使用。取消或导入失败时保留原背景。图片按比例铺满并叠加暗色遮罩，边缘可能裁切；棋盘底板继续保持不透明。内置图片随 SwiftPM 资源包离线分发，无需联网。

### 对战反馈与视觉层级

双人棋盘旁显示上次交互的发送、抵消和实际进入行数，待接收队列始终显示总行数与下一次最多 8 行的分段预告。垃圾行仍按原规则在未消行锁定后进入，消行可先抵消，提示不延迟或改变规则。

危险状态只依据锁定方块和下一批待进入垃圾行预测：最高方块距顶端不超过 8 行时显示橙色边框，不超过 5 行时显示红色边框，恢复安全后移除；活动方块不触发预警。进入危险等级时短促提示，同一玩家至少间隔 5 秒，暂停或关闭声音不补播。设置 → 声音与动效提供危险提示音开关、音量和持久化的减少动效选项，仍尊重系统减少动态效果。

活动方块使用明亮立体材质，锁定块使用较暗哑光材质，投影使用白色空心细线框。普通消行使用较少青色碎片，四行使用金色环，连击使用粉色环与 COMBO 标识，全清使用白色加强环；奖励文字限制在棋盘上方，避免遮挡落点。减少动效时保留短光束、HUD 和稳定危险边框，切换时立即清理已有动态粒子。单人右侧显示下一等级目标与纪录进度。
